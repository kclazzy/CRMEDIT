# CRMEDIT

Редактор-конструктор CRM на Rust. Вы описываете свою CRM мышью и русскими названиями —
разделы, поля, связи, — сразу видите её в работе и одной кнопкой получаете установочник
Windows с готовой программой.

- **Техническое задание:** [docs/TZ.md](docs/TZ.md) — требования, критический разбор, состояние этапов, известные ограничения.
- **Журнал работ:** [docs/LOG.md](docs/LOG.md) — что и почему сделано.

## Скачать

Готовые программы для Windows 10/11 x64 — на странице
[Releases](https://github.com/kclazzy/CRMEDIT/releases). В архиве:

| Файл | Что это |
|---|---|
| `crmedit.exe` | Редактор. Запустите его. |
| `crmedit-cli.exe` | То же из командной строки — для автоматизации. |
| `Demo-setup.exe` | Пример результата: установочник CRM «Магазин у дома», собранный редактором. |

Программы не подписаны, поэтому Windows SmartScreen при первом запуске спросит
подтверждение: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

1. Запустите `crmedit.exe`. Введите название CRM, выберите папку проекта, нажмите **«Создать проект»** —
   шаблон «Продажи» сразу даёт клиентов, сделки и задачи.
2. Вкладка **«Структура»**: добавляйте разделы и поля, меняйте названия прямо в таблице,
   порядок, обязательность; ненужное скрывайте. Каждая правка сохраняется сама.
3. Вкладка **«Предпросмотр»**: это настоящая CRM — заведите пару записей и проверьте, удобно ли.
4. Вкладка **«История»**: каждая правка — версия; к любой можно вернуться, ничего не теряя.
5. **«Собрать установочник»** — получите один файл `…-setup.exe`. Его и отдавайте пользователям.

У пользователя: запуск установочника → «Установить» → ярлык на рабочем столе и в меню «Пуск».
Права администратора не нужны. Новая версия ставится поверх старой, данные сохраняются
(перед изменением базы делается её копия). Удаление — через «Программы и компоненты»;
данные при удалении остаются, если явно не попросить стереть и их.

Несколько проектов — несколько папок; переключение — в списке «Проект» вверху окна.
Папку проекта можно копировать и переносить: история версий лежит внутри неё, в `history/`.

## Командная строка

```
crmedit-cli new shop --name "Магазин"
crmedit-cli entity add supplier "Поставщики"
crmedit-cli field add supplier name "Название" text --required
crmedit-cli field add deal stage2 "Вид" "choice:Опт,Розница"
crmedit-cli history
crmedit-cli restore 1
crmedit-cli build Магазин-setup.exe
crmedit-cli projects
crmedit-cli --help
```

## Разработка

```
cargo test --workspace                                   # 150+ тестов, включая тесты окон
cargo clippy --workspace --all-targets -- -D warnings
cargo mutants                                            # мутационное тестирование
```

| Крейт | Назначение |
|---|---|
| `crates/crm-core` | Описание CRM, проекты, история, реестр. Без окон и без базы. |
| `crates/crm-runtime` | Рабочая CRM: значения, база SQLite с переносом данных, окно. |
| `crates/crmedit` | Редактор (окно и командная строка), сборка установочника, установка. |

Установка, обновление и удаление проверяются на настоящей Windows при каждом изменении:
[`ci/windows-e2e.ps1`](ci/windows-e2e.ps1).
